SmartGit

An AI-Powered Natural Language Git CLI

Translating human intent into strict Git execution using Local LLMs.

1. The Problem Statement

  • Git is powerful but relies on rigid, complex syntax.
  • Developers often break flow state to look up specific flags and commands.
  • Mistakes in commands like git reset or git rebase can cause major issues.
  • Need a bridge between casual natural language and exact version control.

2. What is SmartGit?

  • A locally-hosted command line tool that acts as an AI Git assistant.
  • Takes plain English inputs like "save my work and upload it".
  • Translates inputs directly into a strict JSON sequence of Git commands.
  • Runs natively in the terminal without requiring external cloud API calls.

3. How It Works (Execution Flow)

  • Step 1 (Input): User runs global command: smartgit "undo last commit".
  • Step 2 (Inference): The prompt is sent to a fine-tuned local LLM (Qwen2.5-Coder).
  • Step 3 (Parsing): The tool extracts the structured JSON command sequence.
  • Step 4 (Guardrail): Terminal displays proposed commands and asks [y/N].
  • Step 5 (Execution): Upon approval, standard OS Git commands execute with feedback.

4. System Architecture

  • Core Language: Python (Native Windows execution).
  • Inference Engine: Ollama (Running local lightweight models).
  • Base Model: Qwen2.5-Coder-1.5B (Open-weights, optimized for code).
  • CLI Integration: Subprocess OS execution wrapped in an interactive shell interface.

5. The Dataset Strategy

  • Synthetic data generation utilizing Python.
  • Created a highly curated dataset.jsonl with 400 targeted examples.
  • Mixed standard verbs ("save", "upload") with natural nouns ("my work", "changes").
  • Target schema enforced strict JSON mapping: {"commands": [{"command": "git", "args": ["add", "."]}]}.

6. Local Model Fine-Tuning (QLoRA)

  • Trained entirely locally using an NVIDIA RTX 4050 (6GB VRAM).
  • Library: Unsloth (Highly optimized for consumer GPUs).
  • Technique: 4-bit Quantization (QLoRA) compressing the model footprint.
  • Trained a targeted LoRA adapter over 60 steps to natively output Git JSON formats without heavy prompting.

7. Overcoming Engineering Challenges

  • Dependency Hell: Encountered major PyTorch, Unsloth, and CUDA version conflicts.
  • Root Cause: Python 3.14 incompatibility with pre-built CUDA tensors.
  • Solution: Strategically downgraded the virtual environment to Python 3.12.
  • Leveraged CUDA 12.4 index to ensure stable GPU acceleration during training.

8. Global OS Integration

  • Transitioned from a local script to a globally available system command.
  • Configured Windows PowerShell to recognize the executable anywhere.
  • Allows seamless execution (smartgit) inside any initialized repository folder across the drive.

9. Safety & Guardrails

  • No Blind Execution: AI outputs are fundamentally unpredictable.
  • User-in-the-loop: Built a hard stop requiring manual confirmation before any state-altering actions.
  • Directory Awareness: Fails gracefully with helpful error messages if run outside a valid repository.

10. Future Machine Learning Upgrades

  • Repository RAG (Retrieval-Augmented Generation): Hooking up a local Vector Database.
  • Enable the model to remember past commits and learn specific naming conventions.
  • Multi-branch automated conflict resolution strategies.

Conclusion

A complete journey from prompt engineering and system integration to local deep learning, fine-tuning, and robust dependency management.
